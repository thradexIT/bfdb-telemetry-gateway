# Identity Mapping Contract

The emulator uses a synthetic mapping:
`EMU-BFDB-01 + 0_1_1 -> BFDB-01 / Circuit 1 / Unit 1`, continuing linearly to Circuit 96, and equivalent mappings for BFDB-02/03.

This rule exists only for the PoC emulator.

Production identity must be explicit evidence-backed configuration. The emulator mapping must never silently become field truth.
