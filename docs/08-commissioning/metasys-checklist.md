# Metasys Integration Checklist

Request from the Johnson Controls integrator:
- installed Metasys version;
- integration engine/controller model (SNE/SNC/NAE/OAS/etc.);
- network path/IP;
- accepted Unit IDs;
- FC03 Holding vs FC04 Input Registers;
- FLOAT32 byte order;
- FLOAT32 word order;
- polling interval;
- timeout;
- retry count;
- expected engineering units;
- stale/invalid handling expectation;
- practical point-count/polling constraints;
- whether quality is consumed as separate points;
- commissioning Modbus client/tool.
